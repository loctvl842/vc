notify-init - dev spec

Port BeastVim's notify (animated card stack) and messages (ui2 interception) into VimClaude. Copy the files, rename to vc.*, recolor from vc.theme, and change only four things the PM spec needs.

PM spec: docs/pm-specs/notify-init.md

Context

cmdheight = 0 and no message handling, so Neovim shows its blocking hit-enter prompt. VimClaude has no card UI; only one vim.notify caller exists (lua/vc/init.lua:62).

How it flows

Green = copied from BeastVim, orange = new or changed.

Research

Repo. Searched vim.notify, cmdheight, msg_show, ui2, zindex, animate. Found vc.finder.view (BeastVim View already), vc.finder.wrap, vc.theme, finder highlight refresh pattern. No message routing, no animation. Reuse.
BeastVim. notify, messages, animate already do this. Extra deps: Theme/Util.colors (use vc.theme), Toast (use notify). Decision: Reuse (copy), Build only 4 changes. Not copied: health, demo test, review/notify, Toast titles, first-line-only spill.

The four changes beyond copying

1 Wrap. BeastVim cards never wrap; here lines wrap to card width, 10 line cap.
2 Narrow fit. Width is min(80, columns - 2), so 40 columns gives 38.
3 Overflow. Oldest cards slide out early when the stack would pass the bottom.
4 Everything is a card. Unmatched kinds become INFO. Prompt kinds (confirm, confirm_sub, return_prompt, number_prompt) stay with ui2 so they can still be answered.

Testing strategy

  • Headless: make test, make lint with the new specs.
  • Bench: n/a, not a hot path.
  • Manual: PM scenarios 1-6 via NVIM_APPNAME=VimClaude nvim: x in preview, burst of vim.notify, 40-column resize, /zzz, light/dark flip, and :s/x/y/c still prompting.

Success criteria

  • E21 shows as a top-right card; no "Press ENTER" anywhere.
  • Finder never pushed or covered; typing uninterrupted.
  • Cards colored by level from the terminal palette, light and dark.
  • Stacking closes gaps; more than 10 lines cut at 10; 40 columns gives a readable 38-wide card.
  • Fast-event messages show with no error; confirm prompts still work.
  • make test and make lint pass.
